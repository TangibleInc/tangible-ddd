# Architecture decision records

One paragraph per decision: the context, what was decided, and why. Files are
numbered `NNNN-slug.md`; take the next free number.

Write an ADR when a decision is hard to reverse, would surprise a reader
without context, and closed off a real alternative. An explicit **owner
ruling** is always recorded, even when it fails that test, because rulings are
what gets re-argued.

The **owner** is the framework maintainer, currently Titus
(titus@teamtangible.com). An ADR marked `accepted (owner ruling)` is settled;
reopening it takes a new ruling and a new ADR that supersedes it.

Status values: `proposed` (awaiting a ruling), `accepted`, `accepted (owner
ruling)`, `superseded by NNNN`.
