# Version tags stay contiguous

Release numbers are never skipped, even when a version number was spoken for in planning and the work planned for it slipped. 0.6.6 shipped as the next release after 0.6.5, although earlier plans had promised 0.6.6 to consumer-qualified causation. That work takes whatever number comes next ([0010](0010-consumer-qualified-causation.md)). A version number names a release, not a planned feature.
